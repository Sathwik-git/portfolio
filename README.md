# Sathwik Bodakuntla Portfolio

Minimal portfolio built with React, Vite, and TypeScript.

## Update content

Edit [src/data/profile.ts](src/data/profile.ts) to change all content (name, bio, experience, projects, skills, contacts, and blog posts). The Blog page reads from the `blogPosts` array in that file.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## SEO files

The site includes:

- [public/robots.txt](public/robots.txt)
- [public/sitemap.xml](public/sitemap.xml)

Update the domain in those files and in [index.html](index.html) if the site URL changes.
